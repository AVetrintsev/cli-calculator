# Трекер задач: локальный Markdown

Задачи и спецификации хранятся в `.scratch/` внутри репозитория. Добавляй эти файлы в Git и проводи их изменения через рабочую ветку и PR/MR согласно `AGENTS.md`.

## Структура и операции

- Для каждой фичи используй каталог `.scratch/<feature-slug>/`.
- Спецификация: `.scratch/<feature-slug>/spec.md`.
- Каждая задача — отдельный файл `.scratch/<feature-slug>/issues/<NN>-<slug>.md`, нумерация с `01` внутри фичи. Не объединяй все задачи в один файл.
- Состояние triage указывай строкой `Status:` в начале файла. Значения описаны в `triage-labels.md`.
- Комментарии и историю обсуждения дописывай в конец файла под заголовком `## Comments`.
- «Опубликовать в трекере» означает создать соответствующий Markdown-файл, при необходимости создав каталог.
- «Получить задачу» означает прочитать файл по указанному пути. Номер задачи разрешай внутри каталога фичи; если одному номеру соответствуют несколько задач и контекст не определяет фичу, уточни путь.
- Для списка задач используй файлы `.scratch/*/issues/*.md` и их строки состояния.
- Завершённую задачу сохраняй вместе с результатом и отмечай `Status: resolved`.

## Операции wayfinder

- Карта работы: `.scratch/<effort>/map.md` с разделами `Notes`, `Decisions-so-far`, `Fog`.
- Дочерняя задача: `.scratch/<effort>/issues/<NN>-<slug>.md`, нумерация с `01`; вопрос записывай в теле файла.
- Тип задачи задавай строкой `Type:` со значением `research`, `prototype`, `grilling` или `task`.
- Для жизненного цикла wayfinder используй `Status: open`, `Status: claimed`, `Status: resolved`. Если нужна отдельная классификация triage, сохраняй её строкой `Triage:` с одной из стандартных меток.
- Зависимости указывай строкой `Blocked by: NN, NN` в начале файла. Задача разблокирована, когда все перечисленные задачи имеют `Status: resolved`.
- Следующая задача — первая по номеру со статусом `open`, без незавершённых зависимостей.
- Перед началом работы запиши `Status: claimed` и сохрани файл.
- При завершении добавь ответ под `## Answer`, запиши `Status: resolved` и добавь краткий вывод со ссылкой на задачу в раздел `Decisions-so-far` карты.
