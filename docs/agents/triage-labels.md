# Метки triage

Используй стандартные имена меток без переименования:

| Роль навыка | Метка в трекере | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Задача требует оценки сопровождающим проекта |
| `needs-info` | `needs-info` | Требуется дополнительная информация от автора |
| `ready-for-agent` | `ready-for-agent` | Задача полностью определена и готова к выполнению агентом |
| `ready-for-human` | `ready-for-human` | Требуется реализация человеком |
| `wontfix` | `wontfix` | Задача не будет выполняться |

В Markdown-задачах записывай метку строкой `Status:` в начале файла. Для задач wayfinder с отдельным состоянием выполнения используй строку `Triage:`, как описано в `issue-tracker.md`.
