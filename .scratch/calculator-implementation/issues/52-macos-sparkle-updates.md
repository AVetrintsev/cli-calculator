# 52: Обновление macOS через Sparkle

**What to build:** Mac использует общий сеанс обновления с тихим интерфейсом и штатной проверкой/заменой через Sparkle.

**Blocked by:** [50 — Подписанная установка macOS](50-signed-macos-installation.md); [51 — Обновление Windows после сохранения](51-windows-update-and-save-barrier.md)

**Status:** ready-for-agent

- [ ] Проверены подписанные две версии, Ed25519, доверенный канал и барьер до первого Install; автоматическая установка отключена, системная ошибка не прерывает офлайн-расчёт.
- [ ] Готовое обновление действительно снимается до возврата редактирования; Dismiss не подменяет отмену. Проверены сбой, миграция и ручной перезапуск с сохранённым рабочим состоянием.

**Покрытие:** сценарии SPEC 66, 67, 68.

**Внешние условия:** Две реальные подписанные и нотариализованные Mac-версии, ключ Sparkle, согласованный канал и Intel/Apple-silicon Mac. Секреты предоставляются вне репозитория.

**Общие условия и нормативные материалы:** [согласованный план](../breakdown.md#как-читать-план), [реестр задач](../README.md).
