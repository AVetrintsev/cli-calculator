# 38: Полные локальные резервные снимки

**What to build:** Приложение публикует проверенные резервные снимки личных данных и сохраняет последние десять исправных копий.

**Blocked by:** [05 — Сохранение быстрого ввода между запусками](05-persist-quick-draft.md)

**Status:** ready-for-agent

- [ ] Работают резервирование при изменениях не чаще раза в день и запрос защитной копии; снимок включает весь текущий SQLite-состав, в том числе историю при её наличии.
- [ ] Публикация происходит после завершения, проверки, синхронизации и переименования; предыдущая исправная копия сохраняется при отказе, очистка идёт после успеха и выдерживает прерывание.

**Покрытие:** сценарии SPEC 55.

**Общие условия и нормативные материалы:** [согласованный план](../breakdown.md#как-читать-план), [реестр задач](../README.md).
