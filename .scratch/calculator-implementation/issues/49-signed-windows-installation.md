# 49: Подписанная установка Windows

**What to build:** Обычный пользователь устанавливает Windows-пакет со всеми компонентами и считает офлайн.

**Blocked by:** [45 — Сочетания, автозапуск и системный значок](45-shortcuts-autostart-and-system-icon.md)

**Status:** ready-for-agent

- [ ] Собраны воспроизводимые подписанные MSIX/.appinstaller и полный пакет; .NET, native-библиотеки, worker, notices и постоянные идентификаторы включены, SDK и обязательный UAC не нужны.
- [ ] На чистой Windows проверены установка, обычный/офлайн-запуск, ремонт и uninstall/reinstall; внешнее личное хранилище и backup сохраняются, исключение виртуализации подтверждено фактически.

**Покрытие:** сценарии SPEC 64, 65, 68, 69.

**Внешние условия:** Постоянные идентификаторы Windows-пакета и издателя, доверенная подпись, согласованный канал и чистая Windows 11 x64. Секреты предоставляются вне репозитория.

**Общие условия и нормативные материалы:** [согласованный план](../breakdown.md#как-читать-план), [реестр задач](../README.md).
