# 11: Поиск и удаление истории

**What to build:** Пользователь ищет по всей истории и управляет записями через её меню.

**Blocked by:** [10 — Навигация по истории у неподвижного ввода](10-history-navigation.md)

**Status:** ready-for-agent

- [ ] Поиск учитывает текст формул/ответов и принятые эквивалентности десятичной записи, группировки и коротких степеней; Enter подставляет формулу, Escape возвращает исходный ввод.
- [ ] Удаление одной записи и очистка всей истории следуют принятому подтверждению и отдельной отмене до полного выхода; новые записи сохраняются, автоматического ограничения истории нет.

**Покрытие:** сценарии SPEC 14.

**Общие условия и нормативные материалы:** [согласованный план](../breakdown.md#как-читать-план), [реестр задач](../README.md).
