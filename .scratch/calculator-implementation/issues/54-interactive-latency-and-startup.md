# 54: Скорость ответа, вызова и запуска

**What to build:** Полный вычислитель и нативные окна укладываются в интерактивные бюджеты на согласованном оборудовании.

**Blocked by:** [27 — Накопления и сложные проценты](27-savings-and-compound-interest.md); [28 — Прибыль, ROI и окупаемость](28-profit-roi-and-payback.md); [44 — Смена языка и локальных обозначений](44-language-and-notation-switching.md); [49 — Подписанная установка Windows](49-signed-windows-installation.md); [50 — Подписанная установка macOS](50-signed-macos-installation.md)

**Status:** ready-for-agent

- [ ] На зафиксированных release-сборках независимые эталоны и один корпус через оба binding подтверждают корректность; p95 ответа <= 50 мс, вызова <= 100 мс, холодного запуска <= 2 с.
- [ ] Для интерактивных задержек сохранены не менее 100 прогонов, для холодного старта не менее 20; измеряется видимый полный результат, узкие места исправлены без изменения семантики.

**Покрытие:** сценарии SPEC 71.

**Внешние условия:** Зафиксированные устройства согласованного класса 8 ГБ RAM/SSD, Windows 11 x64 и macOS 14+ на Intel/Apple silicon; release-сборки и исходные замеры сохраняются.
