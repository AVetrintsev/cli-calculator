# 05: Сохранение быстрого ввода между запусками

**What to build:** Последний действительно сохранённый черновик, курсор и начальные настройки переживают полный выход и запуск.

**Blocked by:** [04 — Глобальный вызов и возврат к работе](04-global-invocation-and-focus.md)

**Status:** ready-for-agent

- [ ] Общий SQLite-модуль атомарно сохраняет предметную команду с ревизией и ID операции; личное хранилище находится вне установки, повторный запуск активирует единственный экземпляр.
- [ ] Отказ записи сохраняет текст в сеансе и даёт повтор/сохранение текста отдельно при выходе; после запуска ввод пересчитывается, временные меню и Undo прошлого сеанса не восстанавливаются.

**Покрытие:** сценарии SPEC 4.

**Общие условия и нормативные материалы:** [согласованный план](../breakdown.md#как-читать-план), [реестр задач](../README.md).
