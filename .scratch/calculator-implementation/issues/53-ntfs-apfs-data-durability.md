# 53: Сохранность данных на NTFS и APFS

**What to build:** Прерывания реального хранения, импорта, восстановления и обновления сохраняют предусмотренный путь продолжения работы.

**Blocked by:** [42 — Импорт с предпросмотром конфликтов](42-import-preview-and-conflicts.md); [52 — Обновление macOS через Sparkle](52-macos-sparkle-updates.md)

**Status:** ready-for-agent

- [ ] На обеих файловых системах проверены отказы записи/места/прав, process-crash, WAL, миграции, поколения, резервирование и длинные поддерживаемые пути; сверяется фактическое содержимое данных.
- [ ] Подтверждены файловая синхронизация и границы долговечности; остановка процесса не объявляется испытанием отключения питания. Любой недоступный обязательный сценарий имеет явный непройденный статус.

**Покрытие:** сценарии SPEC 57.

**Внешние условия:** Тестовые Windows/NTFS и macOS/APFS, обе поддерживаемые архитектуры Mac и воспроизводимые сценарии отказов. Доступ к необходимому оборудованию должен быть подтверждён.

**Общие условия и нормативные материалы:** [согласованный план](../breakdown.md#как-читать-план), [реестр задач](../README.md).
