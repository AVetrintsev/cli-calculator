# 41: Полный и выборочный экспорт

**What to build:** Пользователь получает переносимый набор листов, шаблонов, определений и выбранного состава общих настроек.

**Blocked by:** [37 — Переименование и удаление определений](37-definition-rename-and-deletion.md)

**Status:** ready-for-agent

- [ ] Полный/выборочный экспорт сохраняет необходимые цепочки зависимостей, стабильные ID, версии, смысловые ссылки и незавершённый текст.
- [ ] История и параметры устройства не входят в переносимый UTF-8 JSON; подготовка файла сохраняет исходные данные, формат одинаков для Windows и macOS.

**Покрытие:** сценарии SPEC 53.

**Общие условия и нормативные материалы:** [согласованный план](../breakdown.md#как-читать-план), [реестр задач](../README.md).
