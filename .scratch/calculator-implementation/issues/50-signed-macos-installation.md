# 50: Подписанная установка macOS

**What to build:** Пользователь устанавливает universal Mac-приложение из DMG со всеми компонентами.

**Blocked by:** [45 — Сочетания, автозапуск и системный значок](45-shortcuts-autostart-and-system-icon.md)

**Status:** ready-for-agent

- [ ] Каждый включённый Mach-O имеет обе нужные архитектуры и минимальную ОС; Developer ID, hardened runtime, нотариализация/stapling, notices и воспроизводимость проверены.
- [ ] На чистых совместимых Intel/Apple-silicon Mac проверены обычная и пользовательская установка, офлайн-работа, ремонт и удаление/повторная установка с сохранением данных.

**Покрытие:** сценарии SPEC 64, 65, 68, 69.

**Внешние условия:** Постоянная идентичность Mac-приложения, Apple Developer ID/нотариализация и совместимые Intel/Apple-silicon Mac. Секреты предоставляются вне репозитория.

**Общие условия и нормативные материалы:** [согласованный план](../breakdown.md#как-читать-план), [реестр задач](../README.md).
