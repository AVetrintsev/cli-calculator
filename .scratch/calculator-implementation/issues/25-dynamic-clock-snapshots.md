# 25: Динамические часы и сохранённый снимок

**What to build:** today/yesterday/tomorrow/now обновляют видимые расчёты, сохраняя согласованность одного ответа и подтверждения.

**Blocked by:** [09 — Подтверждение расчёта без потери данных](09-confirmation-and-history.md); [24 — Календарные месяцы и фиксированные смещения](24-calendar-intervals-and-offsets.md)

**Status:** ready-for-agent

- [ ] Один запрос использует один снимок часов/смещения; проверены секунда, смена суток, сон, системные изменения, скрытие и повторный вызов.
- [ ] История остаётся фиксированной; частичное подтверждение замораживает показанный снимок до повтора/отказа, полный перезапуск не продолжает старую попытку.

**Покрытие:** сценарии SPEC 32.
