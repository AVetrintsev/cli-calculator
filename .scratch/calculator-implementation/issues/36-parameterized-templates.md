# 36: Шаблоны с параметрами

**What to build:** Пользователь сохраняет лист как шаблон и запускает его с параметрами в самостоятельный именованный лист.

**Blocked by:** [33 — Пользовательские функции с аргументами](33-user-functions-with-arguments.md); [35 — Каталог и управление сохранёнными объектами](35-catalog-and-object-management.md)

**Status:** ready-for-agent

- [ ] Параметры выбираются из локальных переменных, имеют значения по умолчанию и обычный язык выражений; компактная форма показывает ошибки у полей, отмена/ошибка не создаёт лист.
- [ ] Изменения экземпляра, обновление шаблона, дублирование, переименование и удаление с отменой сохраняют самостоятельность объектов и живые глобальные зависимости.

**Покрытие:** сценарии SPEC 51, 52.

**Общие условия и нормативные материалы:** [согласованный план](../breakdown.md#как-читать-план), [реестр задач](../README.md).
