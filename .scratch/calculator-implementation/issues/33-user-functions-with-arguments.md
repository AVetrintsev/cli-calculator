# 33: Пользовательские функции с аргументами

**What to build:** Сохранённая функция вычисляет выражение с параметрами и вызовами других определений.

**Blocked by:** [32 — Публикация пользовательских констант](32-publish-user-constants.md)

**Status:** ready-for-agent

- [ ] Параметры изолированы от локальных имён вызывающего листа; глобальные ссылки стабильны, встроенные имена защищены, перегрузки по числу аргументов не вводятся.
- [ ] Проверены черновик/публикация, описание и подсказки, запрет рекурсии и то, что допустимость определения не требует успеха при любых аргументах.

**Покрытие:** сценарии SPEC 36, 37, 45, 47.

**Общие условия и нормативные материалы:** [согласованный план](../breakdown.md#как-читать-план), [реестр задач](../README.md).
