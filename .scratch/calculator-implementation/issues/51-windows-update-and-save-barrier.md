# 51: Обновление Windows после сохранения

**What to build:** Приложение тихо показывает новую версию и начинает установку по команде после успешной защиты работы.

**Blocked by:** [40 — Миграции, новый формат и повреждённая база](40-storage-migration-and-recovery.md); [49 — Подписанная установка Windows](49-signed-windows-installation.md)

**Status:** ready-for-agent

- [ ] На двух реальных подписанных версиях проверены канал, обычная и офлайн-установка, отказ сети/подписи/совместимости, барьер сохранения и проверенного backup до передачи App Installer.
- [ ] Общий сеанс обновления блокирует новые несохранённые правки после разрешения, подтверждает остановку worker и действительную отмену; следующий успешный запуск восстанавливает собственное рабочее состояние.

**Покрытие:** сценарии SPEC 66, 67, 68.

**Внешние условия:** Две реальные подписанные Windows-версии, постоянная идентичность издателя, согласованный канал доставки и чистое тестовое окружение.

**Общие условия и нормативные материалы:** [согласованный план](../breakdown.md#как-читать-план), [реестр задач](../README.md).
