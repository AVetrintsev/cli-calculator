# 03: Первый расчёт в macOS

**What to build:** Нативное Mac-приложение выполняет тот же небольшой расчёт через общее ядро.

**Blocked by:** [02 — Первый расчёт в Windows](02-first-windows-calculation.md)

**Status:** ready-for-agent

- [ ] AppKit-редактор показывает те же результаты и состояния, что Windows, на одном корпусе команд через оба binding.
- [ ] Зафиксированы сборки для Intel и Apple silicon; запуск и поведение подтверждаются на соответствующей macOS, а не только кросс-компиляцией.

**Покрытие:** сценарии SPEC 3.

**Общие условия и нормативные материалы:** [согласованный план](../breakdown.md#как-читать-план), [реестр задач](../README.md).
