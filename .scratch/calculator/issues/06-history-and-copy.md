## Question

Учесть [Отображение нескольких результатов lazy вычисления](17-alternative-results-layout.md): одна формула может дать несколько допустимых ответов. Клик по ответу уже выбран как способ скопировать нажатую запись; Ctrl+C без выделения копирует готовый однозначный результат текущей формулы. Требуются оставшиеся правила клавиатурного выбора, поведения по умолчанию, сохранения набора/выбранной трактовки в истории и повторного вычисления. Одинаково выглядящие ответы объединяются только на уровне отображения, без подписей; разные исходные значения могут совпасть после округления. Требуется правило копирования и дальнейшего использования такой общей записи без молчаливой потери исходных вариантов. Визуальный макет не утверждает копирование первого ответа автоматически.

Когда выражение становится записью истории и что именно делают Enter, Ctrl+Enter и соответствующие команды macOS в каждом режиме? Как копируется результат и что происходит с окном, фокусом и черновиком после копирования?

Определить переход по истории стрелками, сохранение текущего черновика при навигации, повторный запуск и редактирование записи, поиск, удаление, очистку, дубликаты и ограничения хранения. Различить результат на момент расчёта и повторное вычисление выражения с изменёнными переменными. Учесть отсутствие результата, отказ доступа к буферу обмена и конфликт команд с многострочным вводом.

Учитывать согласованное [поведение быстрого ввода](03-quick-palette.md): вверх автоматически раскрывает историю и опускает весь список в консоль, вниз сдвигает его обратно; возврат к пустому новому вводу автоматически сворачивает историю. Выбранное выражение редактируется как копия, исходная запись не изменяется. Стрелка вверх не является отдельной командой возврата к отложенному черновику. Начало нового ввода само по себе не означает вычисления выражения или добавления его в историю; эти события нужно согласовать отдельно. Также определить судьбу правок копии при дальнейшей навигации. В расширенном режиме обычные стрелки предназначены только для текстового редактирования; выход к истории выполняется отдельной командой с модификатором.

Предыдущий ответ не считается результатом текущего ошибочного или незавершённого ввода. Само форматирование для копирования ещё уточняется в текущем вопросе.

### Дополнение пользователя — быстрое копирование результата

Текущие уточнения обсуждаются по явному дополнению пользователя во время работы над связанным вопросом единиц. Вопрос взят в работу; зависимости для полного решения сохраняются, вопрос целиком не разрешён.

Прямое требование пользователя:

- В редакторе формулы нет выделенного текста, курсор может находиться в любой позиции; для текущей формулы есть готовый однозначный результат. Ctrl+C копирует именно результат, а не формулу или текущую строку.
- Если текст выделен, обычное копирование сохраняет выделение. Для выделенной формулы уже принят видимый текст с настоящими ²/³ в [Контекстное определение единиц и автоматическая запись степеней](16-contextual-units.md), раунд 9.
- Клик по результату копирует нажатый результат. Для ряда разных ответов это явное указание на нужную видимую запись, а не копирование первого ответа.
- Отсутствующий, ошибочный или устаревший ответ не становится копируемым результатом. Это следует из ранее принятого запрета копировать отсутствующий результат; выделенный текст формулы можно копировать независимо от её вычислимости.

Пока не определено: граница «однозначности» при объединении нескольких смыслов или разных рабочих значений в одинаковую видимую запись; реакция Ctrl+C без выделения при нескольких видимых ответах. Нажатие на объединённую запись само по себе не выбирает молча одну из скрытых трактовок. Действие для многострочного листа, история и выбор активного расчёта ещё требуют отдельного контракта. «Опция» здесь фиксирует запрошенную возможность, не утверждает новый переключатель настройки.

### Раунд 1 — предложения

1. Для macOS использовать Cmd+C с теми же условиями, что Ctrl+C на Windows. Рекомендовано стандартное платформенное сочетание копирования. Значение подставляется в локализованные подсказки, а не жёстко задаётся в переводах.
2. После успешного быстрого копирования через сочетание или клик оставлять окно открытым, формулу и позицию курсора сохранять; возвращать фокус вводу после клика. Само копирование не добавляет запись в историю. Рекомендовано отделить это действие от подтверждения расчёта через Enter/Ctrl+Enter, чьи правила ещё открыты.
3. Копировать текст результата так, как он показан, с отображаемым округлением, всеми показанными цифрами (включая приглушённые), единицами, префиксами системы счисления и показанной группировкой. Пример: для показанного результата 1/3 скопировать `0,3333333333`, а не скрытое более точное значение. Рекомендовано совпадение с экраном. Это предложение не выбирает скрытую трактовку и не меняет рабочую точность ядра.

### Раунд 1 — ответы пользователя

Пользователь ответил «ок» на все три предложения.

1. Приняты Ctrl+C на Windows и Cmd+C на macOS с одинаковыми условиями: выделение копируется как текст, а без выделения копируется готовый однозначный результат текущей формулы. Сочетание подставляется в локализованные подсказки через параметр платформы.
2. После успешного быстрого копирования сочетанием или кликом окно остаётся открытым; формула и позиция курсора сохраняются, после клика фокус возвращается вводу. Само быстрое копирование не добавляет запись в историю. Действия Enter/Ctrl+Enter и команды подтверждения ещё согласуются отдельно; это решение не утверждает их поведение.
3. Быстрое копирование передаёт показанный текст результата: отображаемое округление, все показанные цифры (в том числе приглушённые), единицы, знак, регистр и префикс системы счисления, показанные разделители разрядов и надстрочные символы. Пример для отображённого 1/3: `0,3333333333`, без скрытого продолжения. Прозрачность и другие стили не являются текстом буфера. Рабочее значение и точность ядра не изменяются; копирование отображения не подменяет исходное значение в дальнейшем расчёте. Для показанного логического результата это также его видимый локализованный текст; литералы логических значений в языке не выбираются этим решением.

### Раунд 2 — ожидаются ответы

1. Для быстрого копирования без выделения считать однозначностью один различимый видимый ответ, даже если он объединяет несколько смыслов или рабочих значений. Например, `2m * 2` показывает одну запись `4m`; предложено разрешить Ctrl+C / Cmd+C и скопировать именно `4m`. Рекомендовано такое поведение: формат копирования уже совпадает с экраном, поэтому выбирать одну из скрытых трактовок не нужно. Семантическая неоднозначность продолжает сохраняться в ядре; понятие одного ответа здесь относится только к доступности действия копирования.
2. Если видимых ответов несколько, например `5m/s` и `300`, а текст не выделен, Ctrl+C / Cmd+C не меняет буфер и кратко показывает подсказку «Выберите результат». Нужный ответ можно скопировать кликом. Рекомендовано не выбирать первый ответ автоматически. Это предложение о реакции сочетания; клавиатурный выбор конкретного ответа остаётся отдельной задачей интерфейса. Точная формулировка подсказки пока предложена, не утверждена.
