## Question

Учесть [Отображение нескольких результатов lazy вычисления](17-alternative-results-layout.md): одна формула может дать несколько допустимых ответов. Клик по ответу уже выбран как способ скопировать нажатую запись; Ctrl+C без выделения копирует готовый однозначный результат текущей формулы. В раунде 6 принят клавиатурный выбор видимого ответа для подтверждения через существующий ряд. В раунде 7 принято сохранение формулы, всего набора ответов и выбранной записи на момент подтверждения; возврат формулы во ввод пересчитывает её с текущими определениями без изменения старой записи. В раунде 8 приняты ряд из формулы и всех сохранённых видимых ответов с полужирным выбранным ответом, горизонтальная прокрутка и отдельная запись для каждого нового подтверждения. В раунде 9 включены поиск, удаление записи с отменой и подтверждаемая очистка истории. Требуются детали этих действий, ограничения хранения и оставшиеся команды выбора; выбор записи не выбирает одну из её скрытых трактовок. Одинаково выглядящие ответы объединяются только на уровне отображения, без подписей; разные исходные значения могут совпасть после округления. Одна видимая запись допускает быстрое копирование её показанного числового значения без единицы; скрытые трактовки сохраняются. Дальнейшее использование набора внутри листа ещё требует правил; отображение сохранённого набора и управление историей уточняются ниже. Визуальный макет не утверждает копирование первого ответа автоматически.

Когда выражение становится записью истории и что именно делают Enter, Ctrl+Enter и соответствующие команды macOS в каждом режиме? Как копируется результат и что происходит с окном, фокусом и черновиком после копирования?

Определить переход по истории стрелками, сохранение текущего черновика при навигации, повторный запуск и редактирование записи, поиск, удаление, очистку, дубликаты и ограничения хранения. Различить результат на момент расчёта и повторное вычисление выражения с изменёнными переменными. Учесть отсутствие результата, отказ доступа к буферу обмена и конфликт команд с многострочным вводом.

Учитывать согласованное [поведение быстрого ввода](03-quick-palette.md): вверх автоматически раскрывает историю и опускает весь список в консоль, вниз сдвигает его обратно; возврат к пустому новому вводу автоматически сворачивает историю. Выбранное выражение редактируется как копия, исходная запись не изменяется. Стрелка вверх не является отдельной командой возврата к отложенному черновику. Начало нового ввода само по себе не означает вычисления выражения или добавления его в историю; эти события нужно согласовать отдельно. Также определить судьбу правок копии при дальнейшей навигации. В расширенном режиме обычные стрелки предназначены только для текстового редактирования; выход к истории выполняется отдельной командой с модификатором.

### Дополнение пользователя — быстрое копирование результата

Текущие уточнения обсуждаются по явному дополнению пользователя во время работы над связанным вопросом единиц. Вопрос взят в работу; зависимости для полного решения сохраняются, вопрос целиком не разрешён.

Прямое требование пользователя:

- В редакторе формулы нет выделенного текста, курсор может находиться в любой позиции; для текущей формулы есть готовый однозначный результат. Ctrl+C копирует именно результат, а не формулу или текущую строку.
- Если текст выделен, обычное копирование сохраняет выделение. Для выделенной формулы уже принят видимый текст с настоящими ²/³ в [Контекстное определение единиц и автоматическая запись степеней](16-contextual-units.md), раунд 9.
- Клик по результату копирует нажатый результат. Для ряда разных ответов это явное указание на нужную видимую запись, а не копирование первого ответа.
- Отсутствующий, ошибочный или устаревший ответ не становится копируемым результатом. Это следует из ранее принятого запрета копировать отсутствующий результат; выделенный текст формулы можно копировать независимо от её вычислимости.

Для быстрого копирования принято: одна видимая запись допускает копирование; при нескольких без выделения буфер сохраняется и показывается «Выберите результат». Копируется показанная числовая часть без единицы. Нажатие на объединённую запись само по себе не выбирает молча одну из скрытых трактовок. Действие для многострочного листа, история и выбор активного расчёта ещё требуют отдельного контракта. «Опция» здесь фиксирует запрошенную возможность, не утверждает новый переключатель настройки.

Стрелка вниз по-прежнему начинает пустой ввод и сворачивает историю, а стрелка вверх по-прежнему листает историю. Отмена текста сама по себе не копирует, не подтверждает расчёт и не отменяет удаление записей истории. Это предложение, а не уже принятый способ хранения/восстановления черновиков; срок хранения стека текстовой отмены между полными запусками и другие детали жизненного цикла ещё требуют отдельного решения.
