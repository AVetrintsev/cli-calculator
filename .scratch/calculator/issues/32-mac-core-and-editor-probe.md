# Общий Rust-сеанс и нативный редактор на Mac

## Question

Подготовить отдельный воспроизводимый Mac-эксперимент: тот же проверенный Rust-сеанс/численный код и C ABI, нативный запуск/остановка/ожидание worker, возврат ответа в AppKit и редактор с визуальными степенями без изменения исходного текста. Различить технический автоматический прогон и ручные действия с настоящим составным вводом. Проверить границу владения дескрипторами и прекращение worker при смерти владельца. Стенд и его неподтверждённые платформенные части не выдавать за готовое приложение.

## Context

У пользователя MacBook Air M3 и работавший Swift command-line tools; точная версия ОС пока не предоставлена, прежний положительный отзыв касался другого минимального прототипа. На текущем Windows-хосте Mac не подключён. Агент готовит весь доступный исходник, запуск, статические проверки и пакет; затем нужен запуск на Mac с сохранением отчёта. Никакой установки ОС/глобальных инструментов, публикации или Developer ID не требуется.

Пользователь разрешил автоматически продолжать технические предпосылки. Продуктовые правила, стиль интерфейса, ядро языка и формат clipboard не пересогласовываются. Системный буфер не использовать в автоматических сценариях. Код остаётся на отдельной ветке прототипа, основной проект получает только результаты и указатель.
