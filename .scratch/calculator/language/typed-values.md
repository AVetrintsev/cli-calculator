# Типизированные числовые значения

Материалы спецификации по прямым уточнениям пользователя и принятым решениям раундов 27–30 [Языка выражений и правил вычисления](../issues/04-expression-language.md). Это модель общего ядра, а не реализация классов или выбор языка программирования.

## Согласованная модель

Числовая величина сочетает опорное числовое значение и тип со своими операциями/ограничениями. Число, процент, длина, площадь, время и другие числовые величины различаются типом. Они наследуют общее числовое поведение; его точность задаёт [численный контракт](numbers.json). Представление дополнительно хранит контекст единицы и явного целевого перевода. Раунд 30 сохраняет единственный масштаб выражения, а при нескольких выбирает из них по числу дробных знаков; полная автоматическая лестница применяется только без унаследованного контекста масштаба. Тип и рабочая величина сохраняются.

| Введённое значение | Тип | Опорное число | Смысл представления |
|---|---|---|---|
| 2 | Обычное число | 2 | Обычная численная запись |
| 1cm | Длина | 0,01 | Сантиметр, базовый масштаб длины — метр |
| 50% | Процент | 0,5 | Коэффициент ставки 50, численный смысл — половина |

Общая операция преобразует опорное число и по умолчанию возвращает экземпляр исходного типа. Пример, прямо выбранный пользователем: abs(-1cm) возвращает длину с опорным 0,01 и показом 1cm; abs(-50%) возвращает процент с опорным 0,5 и показом 50%. Метаданные смыслового контекста не теряются при операции или передаче по имени; итоговый масштаб измерения теперь может выбрать форматирование.

Примеры единиц здесь даны в латинской базовой записи. Сохранение типа и смыслового контекста не меняет ранее принятого выбора локального обозначения при показе и сохранения явно указанной цели преобразования. Автомасштабирование не подменяет такую цель.

Тип может ограничить унаследованную операцию или переопределить её сочетание с другим типом. Переопределённый метод процента приоритетнее метода другого сочетающегося типа. Это выбор правила вычисления, а не изменение грамматического приоритета +, *, :: или to. Порядок левого и правого аргументов сохраняется.

## Уже выбранные специальные правила

| Операция | Согласованное поведение |
|---|---|
| Число + процент справа | Относительное увеличение: 200 + 10% = 220 |
| Процент слева + обычное число | Обычная доля, числовой результат: 10% + 200 = 200,1 |
| Процент слева - обычное число | 10% - 200 = -199,9 |
| Сумма/разность ставок | Процентный результат: 10% + 5% = 15% |
| Умножение/деление обычных чисел и процентов | Специальное правило раунда 26 возвращает обычное число: 50% * 2 = 1; 200 * 10% = 20. Новая модель позволяет такое переопределение, не отменяя принятое правило автоматически |
| Умножение измерения на скаляр | Сохраняет тип измерения: 2cm * 2 = 4cm |
| Степень всей длины | Ранее принят переход размерности: (2m)^2 = 4m² при трактовке m как метра |
| Отношение величин | Возможны иной тип/безразмерное число по ранее принятым правилам единиц, например варианты 10m / 2s |

Сохранение типа — общее числовое поведение. Таблица специальных правил может задать другой результирующий тип, размерность или отказ. Общая числовая реализация сама по себе не разрешает запрещённые сочетания и не должна молча стирать тип, чтобы получить ответ.

## Lazy вычисление и ограничения

Каждая допустимая трактовка имеет свой тип и опорное значение. Операции и ограничения типа применяются к этой трактовке с учётом всей формулы. Согласованность повторного использования именованного результата сохраняется: a=1m; a/a не смешивает разные трактовки одного a. Недопустимые ветви фильтруются по ранее принятому правилу; одинаковый показ может объединять разные сохранённые значения, но не лишает их типов.

Числовая базовая модель не отменяет запрет арифметики над логическими значениями и start/end. Составной календарный срок сохраняет месячную и фиксированную части; дата/время сохраняют календарный контекст, смещение и перенос суток. Их принятые ограничения и структура не заменяются голым скаляром из-за общей терминологии числового наследования. Достаточность одной числовой опоры определяется конкретным типом и уже согласованной семантикой.

≈ 0 — только представление слишком малого ненулевого опорного значения. Оно готово к копированию/подтверждению; буфер равен 0, но вычисление и история сохраняют настоящее значение с типом. Точный нуль и приблизительный нуль визуально различны и не объединяются в один показанный ответ. Суффикс единицы/процента сохраняется; одинаковые приблизительные ответы группируются с сохранением всех вариантов.

## Принятые специальные правила раунда 28

| Операция | Принятое поведение |
|---|---|
| round/floor/ceil | Преобразуют опорное число и сохраняют тип; round(12,345%; 2) = 12%. Масштаб единицы выбирается при показе: floor(1234mm) = 1000mm: опорный результат 1 метр, единственный масштаб mm сохраняется |
| Корни измерений | Специальный переход размерности: sqrt(4m²) = 2m. Отдельный sqrt(4m) не имеет поддерживаемой итоговой единицы |
| Степень/корень процента | Специальный числовой результат: (50%)^2 = 0,25; sqrt(25%) = 0,5 |
| Измерение + обычное число | Ошибка без угадывания единицы: 1cm + 2 |
| Измерение и процент | 100cm * 50% и 50% * 100cm дают длину 50cm; 100cm + 10% даёт длину 110cm. Форматирование использует только унаследованные масштабы; единственный cm сохраняется. 10% + 100cm отклоняется |
| min/max | Совместимые значения сравниваются по опоре; возвращается выбранный тип/значение и контекст. При равенстве — первый аргумент. Окончательный масштаб измерения выбирает форматирование |
| Логарифмы/тригонометрия | Обычное число и численная доля процента допустимы; длина/площадь/масса/длительность отклоняются. Явные допустимые углы для тригонометрии сохраняются. Результат числовой, кроме углового результата обратной тригонометрии. ln(100%) = 0, sin(1cm) — ошибка |
| if и возврат по имени | Выбранное значение сохраняет тип и рабочую величину |

Математические области функций, градусы по умолчанию и поддержанные итоговые единицы остаются прежними. Общие примеры сочетаний не добавляют новых календарных/температурных операций.

## Масштаб результата

По принятому раунду 30 единственный масштаб выражения сохраняется. floor(1234mm) превращает опорное 1,234 метра в 1 метр и показывает **1000mm**; floor(150cm) показывает 100cm. Это заменяет прежний безусловный автомасштаб в 1m. Копируется показанный коэффициент с обычным числовым форматированием.

Если масштабов несколько, выбирается коэффициент с меньшим числом дробных знаков в рабочей точности до экранного округления, без конечных незначащих нулей. При равенстве выбирается более крупная единица: 1m + 100mm = 1100mm, 1m + 1000mm = 2m, 1km + 1mm = 1 000 001mm. Смешение семейств не расширяет и не сужает набор использованных масштабов. Контекст передаётся через имена и функции; min/max возвращают контекст выбранного аргумента.

Явная цель приоритетна: 1m + 100mm to m = 1,1m. Обычные измерения, информация, фиксированные длительности и числитель производных единиц следуют общей политике: 90s остаётся 90s, 1500m/s остаётся 1500m/s. Полные лестницы раунда 29 используются только без унаследованного контекста масштаба. Контекст знаменателя и отдельные календарные/температурные/угловые/процентные правила сохраняются.

Выбор единицы предшествует форматированию коэффициента, включая ≈ 0, и группированию видимых ответов. Рабочая величина и типы lazy вариантов не меняются. История сохраняет свои исходные значения и показ, копирование не запускает повторный выбор масштаба. См. [контракт показа единиц](unit-display.json).
