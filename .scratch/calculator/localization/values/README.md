# Value notation

[catalog.json](catalog.json) gives stable IDs, English text, meaning, execution context, location and element type for logical input literals and dynamic calendar names. [en.json](en.json) is the always-active Latin baseline; [ru.json](ru.json) adds only the active Russian spellings. New locales add one matching file. Result labels are separate: true/false input produces localized Yes/No output through the main UI catalog. Do not register output text as an extra input alias automatically.

Round 23 approves true/false and да/нет, logical conditions without numeric coercion, and ordinary completion descriptions. Financial timing symbols stay in the [financial notation catalog](../functions/README.md); their general value behavior is now accepted. [Value semantics](../../language/value-semantics.md) records the shared contracts.

Round 24 accepts today/сегодня, yesterday/вчера, tomorrow/завтра and now/сейчас as protected dynamic values without parentheses. Date values use the current system calendar context; now includes time. One clock snapshot is shared by a calculation, visible dependencies refresh when appropriate, saved formulas remain dynamic and history remains fixed. See the [calendar contract](../../language/calendar.json) and [calendar decision](../../issues/19-calendar-and-clock.md). Month/year and offset spellings remain pending and are not registered by this catalog.
